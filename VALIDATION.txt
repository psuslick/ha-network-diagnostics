Network Diagnostics v0.3.2 — package validation

STATUS: PACKAGE-VALIDATED (not live VERIFIED)

Acceptance contract:
  SUCCESS_CRITERIA.md, criteria 1-50.

Live findings carried into this patch:
  - v0.3.0 loaded and discovered Kuma monitors but failed its first live UX acceptance test.
  - v0.3.1 corrected Integrations-page visibility, setup-state UX, and install-manifest metadata.
  - v0.3.1 then failed live Reconfigure because two DNS monitors querying the same hostname were falsely classified as the same resolver endpoint.

Corrective behavior in v0.3.2:
  - DNS monitored hostname/query name is never treated as resolver endpoint identity.
  - When resolver endpoint identity is unavailable through the supported public HA surface, identity is unknown rather than guessed.
  - Unknown identity does not block configuration as duplicate evidence.
  - Unknown identity also does not increase independence-based coverage/confidence.
  - Initial setup and Reconfigure offer native JSON configuration upload as an alternative to the guided manual flow.
  - Portable import matches canonical Kuma monitor names, resolves them to local stable monitor identities, validates missing/ambiguous/invalid references, and requires the same final review step before saving.
  - Portable import deliberately excludes monitored targets, credentials, HA entity IDs, and config-entry IDs.
  - A generic synthetic example is included in the distributable source; user-specific import files remain outside the package.

Preserved architecture:
  - Uptime Kuma is the raw probe/history authority.
  - Network Diagnostics performs no duplicate network probes.
  - Generic explicit topology/roles; no vendor/provider deployment profile restored.
  - Kuma Tags are optional setup hints, not runtime authority.
  - Public HA registries/states only; no Uptime Kuma private runtime_data access.
  - Adaptive response-time samples are bounded RAM-only.
  - Persistent Network Diagnostics history is compact derived incident data only.
  - Downloaded diagnostics remain privacy-reduced.
  - Home Assistant Recorder configuration is not modified.
